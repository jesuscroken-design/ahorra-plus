# 🐷 Ahorra+ · Ahorro y metas

App personal de ahorro con metas futuras, asistente de IA, notificaciones, tema blanco/negro y sonidos. PWA lista para iPhone.

## ✨ Funciones

- 🎯 Metas de ahorro con barra de progreso, emoji automático y fecha límite
- 🤖 Asistente de ahorro con consejos, respuestas y chequeo diario
- 🔔 Notificaciones (iOS/móvil) al cumplir metas, depósitos o recordatorios
- ⚫⚪ Tema blanco/negro (y automático según el sistema), acentos personalizables
- 🔊 Sonidos de clic, dinero y victoria (WebAudio)
- 👋 Saluda con tu nombre al abrir la app
- 🍪 Todo se guarda en tu dispositivo (sin cuentas, sin servidores)

## 📱 Instalar en tu iPhone

1. Abrir la URL en Safari
2. Botón **Compartir** → **Añadir a pantalla de inicio**
3. Ya la tienes como app con su icono; permisos de notificaciones al abrirla

## 🚀 Despliegue

Proyecto estático: cualquier hosting de archivos vale. En Vercel: `vercel deploy`.

## 🛠️ Generar los iconos (opcional)

```bash
python scripts/make_icons.py
```
